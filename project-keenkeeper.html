KeenKeeper

Personal Relationship Management App

Project Summary

A personal relationship management app — your digital shelf of meaningful connections. Features a friendship timeline, interaction logging (call, text, video), and a Recharts-powered analytics dashboard with donut charts showing friendship stats by interaction type.

Primary Tech Stack

  • React 19
  • Vite
  • Tailwind CSS v4
  • DaisyUI v5
  • React Router v7
  • Recharts

Challenge Faced

Aligning skill badges within project cards according to their category classes was tricky — getting the CSS layout logic right so badges grouped and positioned correctly (without breaking on different card sizes) required several rounds of refinement.

Future Improvements

Adding more data visualization (charts) to the dashboard for deeper insights, introducing a dark mode option, and further optimizing performance for faster load times.
