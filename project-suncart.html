SunCart

Summer E-Commerce Web App

Project Summary

A fully responsive summer-themed e-commerce platform built with Next.js 16 and React 19. Features a product catalog with ratings and stock info, secure user authentication via Better Auth, smooth animate.css transitions, a Swiper.js brand carousel, and a warm golden amber UI powered by HeroUI v3. Deployed on Vercel.

Primary Tech Stack

  • Next.js 16
  • React 19
  • HeroUI v3
  • Better Auth
  • MongoDB

Challenge Faced

Resolved a MongoDB Atlas DNS SRV connection failure, and fixed a NavBar hydration mismatch caused by Windows-style line endings.

Future Improvements

Integrating a real payment gateway (such as SSLCommerz, given regional payment support constraints), adding a wishlist/favorites feature so users can save preferred products, and introducing a product reviews and ratings system for customer feedback.
