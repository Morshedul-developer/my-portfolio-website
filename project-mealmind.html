MealMind AI

AI-Assisted Recipe Platform

Project Summary

An AI-assisted recipe platform where users can explore a curated recipe library with advanced search and filters, generate brand-new recipes from available ingredients using AI, chat with a recipe-aware AI assistant, and publish, rate, and review their own recipes.

Primary Tech Stack

  • Next.js 16 (App Router, React 19)
  • TypeScript
  • Tailwind CSS v4
  • TanStack Query & Axios
  • Better Auth (email/password + Google OAuth)
  • Recharts
  • Express + MongoDB backend
  • Groq (Llama 3.3 70B) for AI features

Challenge Faced

Since the frontend and backend are deployed on separate domains (Vercel and Render), the authentication session cookie would normally be treated as third-party — already blocked in Incognito browsing and increasingly blocked as browsers phase out third-party cookies entirely. I solved this by configuring a Next.js rewrite so all browser-side API requests go through a same-origin /api/* path, making the backend's session cookie first-party from the browser's perspective.

Future Improvements

Expanding the meal/recipe recommendation logic to be more personalized, and enhancing the user authentication and profile system with richer account management features.
